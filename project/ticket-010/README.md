# PLF-010 — Sticky text visibility

Distinguish ordinary text scrolled behind an explicitly declared opaque sticky
header from visible text collisions, on the root surface or an explicit frame.
Keep headings, current fragment targets and interactive/focused controls checked.
Missing or unsupported evidence blocks completeness; no blanket rule suppression.

Acceptance: real-browser positive and negative coverage, retained scoped evidence,
unchanged heading/control findings, and reruns on local C2004 and DisplayNet.
Canonical behavior and bounded validation: [UX strategies](../../docs/information/ux-strategies.md).
